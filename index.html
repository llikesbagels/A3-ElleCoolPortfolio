★ MY PROJECTS ★

Original Graphic Novel Pitch

"The Spectacles"

I've always wanted to create an original graphic novel and or series since I was a small child watching cartoons on TV, and this was proof of concept and plan for one of the stories that have been running through my head for a long time. BEAR CHARACTER SHEET

"Crunk the Bear"

Digital Character Sheet, made using Photoshop, When creating this drawing, I focused a lot on using gradient maps to colour Crunk. It was an interesting learning experience, I had never started colouring in only grayscale before and even though I still don't prefer it, I did enjoy learning how it made me think harder about value shading.

WHEELS: STRATFORD BUS

"Figma App Prototype"

This is a prototype of an Bus tracking system app that my team designed for a project in my UX/UI class. The goal of this project was to solve a design problem plaguing students, so we designed an app that tracked the bus better than the current system does. We used Figma to make this prototype and I think it turned out pretty well. I was able to make it interactive and it looks pretty good. I would love to expand on this project and make it into a real application one day.

REFLECTION MAGAZINE

"Magazine Cover and Spread"

This magazine was done in Photoshop and Adobe Indesign as a reflection of my first year of GBDA inspired by 90s skateboard magazines and how I felt about it at the time, The intent with this magazine was to find interesting artworks within Kitchener, Waterloo, but I found that what was more interesting was commercial structures and graffiti instead of the commercial city art which sucked. I originally wanted to do something more commercial and incorporating current design trends, but turns out minimalism is too little for personal work.


MYLAR ILLUSTRATION

"Maria"

Abstract Mixed Media Artwork made on a 18 x 24 sheet of mylar plastic with graphite pencil, coloured pencils and alcohol-based markers. ​ This project was a real chance to prove that I know what I'm doing in regards to realism and detail. Working with mylar is really mean, it smears like crazy and trying to erase more moves what you're trying to erase than actually erasing it. I loved working with the new material though, it was super smooth and softer graphite really do glide across it like butter
